# Tatton Interiors website

Static site for www.tattoninteriors.co.uk. Tatton Interiors is a trading name of Tatton Projects of Cheshire Limited (a Tatton Projects company, DPG Holdings group).

Vercel serves this branch (`tatton-interiors-site`) as it is, with no build step. The pages are generated by `_src/gen.py`, so change the generator, not the `.html` files:

    mkdir -p site && cp styles.css site.js site/
    TI_EMAIL=info@tattoninteriors.co.uk python3 _src/gen.py
    cp -r site/. .

`site/` is a scratch folder and is ignored by git.

## Search engines

- `sitemap.xml`, `robots.txt`, `llms.txt` and `llms-full.txt` are written by the generator.
- `.github/workflows/indexnow.yml` tells Bing and the other IndexNow search engines about every page each time this branch changes. Its key is the `.txt` file at the site root.
- Google reads `sitemap.xml`. Submit it once in Google Search Console.
